# Glossary

**Curated model catalogue**
A limited set of speech models selected and described by Transcriber for useful, supported transcription choices.

**Recommended models**
Models that have passed the evidence required for normal work. A suggested task row can point to a Candidate without making it Recommended.

**Expanded catalogue**
The searchable full 19-model list opened with "Show all 19 models".

**Experimental model**
A curated model with limited validation, unusual constraints, or known issues that is labelled separately from models recommended for normal work.

**Accuracy first**
A recommended transcription choice that favours recognition quality over model size, memory use, and speed.

**Options card**
The Job options section in the main flow. It contains current-job choices and adapts them to the selected model.

**Audio-length limit**
The maximum input duration that Transcriber allows for a selected model before blocking the job to avoid known accuracy degradation.
